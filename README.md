# Simple Unity Game

Projeto desenvolvido com o objetivo de **praticar conceitos básicos de programação de jogos utilizando a Unity**.

Este projeto não tem foco comercial, sendo apenas um ambiente de aprendizado para explorar mecânicas, scripts e funcionamento da engine.

---

## Objetivo

O principal objetivo deste projeto é:

* Aprender os fundamentos da Unity
* Praticar programação em **C#**
* Entender conceitos básicos de jogos, como:

  * Movimentação de personagem
  * Colisão
  * Interação com objetos
  * Lógica de gameplay

---

## Funcionalidades

Atualmente o projeto inclui:

* Movimentação básica do jogador
* Sistema de colisão
* Interação com o ambiente
* Audio (música e efeitos sonoros)
* Scripts simples em C# para controle do jogo
